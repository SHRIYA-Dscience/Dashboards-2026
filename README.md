# Dashboards-2026
### Airline Performance Analysis Dashboard 

**Project Overview**

The Airline Performance Analysis Dashboard is an interactive Power BI report designed to analyze airline operations, passenger trends, ticket booking statuses, and flight distribution.

This dashboard helps stakeholders quickly identify performance patterns, monitor booking behavior, and make data-driven decisions.

🎯 **Objectives**

- Analyze airline performance based on passengers and flights.

- Monitor ticket booking statuses such as Confirmed, Cancelled, and Pending.

- Compare total passengers across different airlines.

- Enable filtering by destination and airline for deeper insights.

- Provide a visually intuitive interface for quick interpretation.

🛠️ **Tools & Technologies**

- Power BI Desktop – Data visualization and dashboard creation

- Power Query – Data cleaning and transformation

- DAX (Data Analysis Expressions) – Calculated measures and KPIs

- Data Modeling – Relationship building between datasets

📌 **Key Features of the Dashboard**

✅ Booking Status Analysis

- Bar chart displaying the count of tickets by booking status.

- Helps identify cancellation trends and booking confirmations.

✅ Passenger Distribution by Airline

- Visual comparison of total passengers for each airline.

- Quickly highlights top-performing airlines.

✅ Flight & Passenger Summary

- Multi-card visuals showing:

  Total Flights

  Total Passengers

  per airline.

✅ Booking Status Breakdown

- Donut chart representing the percentage distribution of:

  Confirmed

  Cancelled

  Pending

✅ Interactive Filters

- Users can dynamically filter the report using:

  Destination slicer

  Status slicer

  Airline selection
